# ARE YOU LOST? / 你也迷路了吗？

> 一款关于前途、贫穷、失去、劳动、意义和活着的文字互动游戏。
>
> **不是人生指南，不是心理测评。这里没有正确选项，也不要求玩家变得积极。**

## 现在就能玩

这是 **v0.1「凌晨 03:17」可玩原型**。

- 下载本仓库的 index.html，直接用现代浏览器打开；无需安装、登录、服务器或 API Key。
- 也可以在仓库 **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)** 开启 GitHub Pages。Pages 发布后，可通过仓库 Settings 显示的链接访问；尚未在此仓库自动启用。
- 首次进入可在候车室选择一个问题，之后自由切换问题、留下文字、导出车票。

目前包含 **6 条主题线、15 个主题回答分支、自由书写、浏览器本地存档与文字导出**。分支可以重玩，游戏不计分。

## 为什么做这个

很多“迷茫”并不是一句“想开点”就能消失的：收入不足以面对意外、选择权有限、努力可能没有回报、技术替代工作的恐惧、失去后的自责，以及“为什么要活着”这个没有标准答案的问题。

这个游戏的宗旨是**陪玩家辨认问题，而非替玩家定义问题**。

我们承认现实的重量，不用轻飘飘的积极话术粉饰困境；也不把痛苦包装成一种必须完成的成长任务。

## 世界

凌晨 03:17，你来到一座没有名字的末班车站。电子屏始终显示「终点站：尚未决定」。

站里只有一位少女。她不介绍自己，也不保证可以回答你的问题。你们在快要天亮的车站里讨论那些白天不敢轻易说出口的事。

视觉与声音的创作方向：日系孤独感、东亚阈限空间、克制的中式都市怪谈、留白与电影式长镜头。**恐怖来自熟悉场景中的缺席，而非猎奇和血腥。**

## v0.1 已实现

- 无账号、零依赖、离线可运行的静态网页
- 6 个互不强制排序的话题：前途 / 金钱 / 未来的工作 / 失去 / 意义 / 活着
- 文字选项通向不同回应，玩家可随时返回候车室
- 随身笔记：手动保存至本机浏览器 localStorage，最多 600 字
- 车票导出：生成本地 TXT 文件
- 重新开始：确认后清除记录
- 移动端响应式布局、键盘焦点、减少动画选项支持
- 清晰的现实求助入口，不把游戏中的 NPC 伪装成专业咨询师

目前是**手写分支叙事**，不是 AI 实时对话。自由输入不会被模型“理解”或分析，避免制造虚假的陪伴承诺。玩家的自写文本保存在当前设备浏览器中，不会发送到服务器；浏览器数据清除后笔记可能丢失，请自行导出。

## 下一步设计

见 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)，包含完整愿景、结构、叙事禁忌与开发路线图。

建议开发优先级：

1. **v0.2：让选择真正留下痕迹。** 回访对白、关键物件、NPC 的局限与变化，不只是一问一答。
2. **v0.3：三幕式完整故事。** 车站的谜团逐步揭示；新增“对照现实”功能，把无法立即解决的问题分成可处理、待协助和无需自责三类，而不是制定不切实际的任务表。
3. **v0.4：内容系统模块化。** 剧本从 HTML 中拆至 JSON/TS，添加剧情节点校验、测试与多语言支持。
4. **v1.0：完整 60–90 分钟叙事。** 多种非优劣结局、结局回响与丰富的环境叙事。支持离线 PWA。

可选的 LLM 对话只在用户明确选择后讨论。若未来接入，必须说明隐私边界、成本、模型的不确定性和危机处理方式；**核心故事不可依赖付费 API 才能通关。**

## 创作约束

1. 不说教、不诊断、不把痛苦强行升华。
2. 不以“想活”或“积极”为答题得分；不以危险行为换取隐藏剧情或奖励。
3. 面对贫穷、劳动、阶层、悲伤等问题，承认结构性限制，不以个体心态替代现实。
4. 提供可跳过的支持信息；若有人处于即时风险中，明确建议现实世界的紧急帮助。
5. 保存的私人文字仅在本地，默认不上传、不统计、不分享。
