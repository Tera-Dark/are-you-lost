# ARE YOU LOST? / 你也迷路了吗？

> **你是这一场戏的主角，但世界并不是为你搭建的舞台。**
>
> 一部关于迷茫、微小选择、因果、他人的世界，以及屏幕外真正的你的交互电影。

## 创作宣言

见微知著：从最小的事件出发，而不是从现成的哲学结论出发。

这个世界不因你而璀璨，社会不因你而运作。你能改变一些人的轨迹，却无法保证结果如愿。每一场戏都有主角，但镜头并不总是对准你。

我们借鉴《史丹利的寓言》对选择与叙事主导权的反思，以及《心跳文学部》对屏幕外玩家的直接凝视；**不复刻其剧情、角色、关系或台词**。

完整的创作原则见 [CREATIVE_VISION.md](docs/CREATIVE_VISION.md)。这份文档是高于具体剧情文本的设计基准。

### 一个镜头

凌晨 03:17，一枚硬币从售货机下滚出。

你可以拾起它追上清洁工、放在台面上、或不去碰它。后来，镜头暂时离开你，跟随清洁工经过一段与玩家无关的生活。

**变化会留下痕迹，但不会自动成为奖励。**

### 目前已实现

- **34 个剧情节点、61 条剧情跳转**，包含 6 类现实困境：前途、金钱、工作、失去、意义、活着。
- **极简放映导航**：候车室只安排少量镜头选择，六个现实主题放在独立的对话场景，避免一屏塞满按钮。
- **因果样片**：硬币的三个选择分支，后续在另一个人物的镜头中产生不同的具体去向。
- **画外世界**：随着剧情主题推进，独立事件继续出现，提醒玩家社会不围绕自己运转。这是**编写好的叙事序列，不是后台实时运行的城市模拟**。
- **第四面墙**：当玩家接触两个主题后，可以去放映机背后，面对“选项中的我”和“真正点击的我”的区别。
- **跨主题回声**：例如谈过钱之后再谈失去，对话会产生微小变化。
- **私人笔记**：可在本机手动保存最多 600 字，导出文本车票，确认后清除所有本机记录。
- **无需注册、无需 API、无广告或服务器上传**；支持移动布局、键盘焦点、减少动画。
- **现实求助入口**：明确区分叙事与现实支持。

### 设计边界

这是 **v0.2 剧情与机制的竖切片**，而不是 60–90 分钟的完整电影，也还没有多人物自主运行的日程系统、真实时间流逝或动态因果图谱。

“平行世界”是作品的叙事约定；“记得你来过”只允许读取游戏在本机保存的剧情选择。游戏不读取真实姓名、通讯录、其他网页或生活数据，不会假装 NPC 真的具有意识。

这不是心理测评或心理治疗游戏：不会按正能量、善良或治愈程度计分，更不会用危险行为解锁特殊剧情。

## 未来版本

1. **v0.3 / 因果剪辑台**：将当前硬币样片发展为真正的 Story Graph；同一事件经多个人物视角逐步重新理解，玩家能看到具体后果却仍然无法掌控全局。
2. **v0.4 / 电影放映系统**：数据化剧本、幕与场、环境镜头、剪辑节奏、可回访的场景物件，完整的自动化分支与可访问性测试。
3. **v0.5 / 他人的章节**：清洁工之外再加入彼此独立的普通人，写他们的现实困境而不是把他们变成玩家的哲学道具。
4. **v1.0 / 完整交互电影**：多次放映回响、非优劣结局、真实代价与未竟之事。纯本地可玩的主线仍是底线。

## 本地隐私与风险提示

笔记与进度保存在当前浏览器的 localStorage，删除浏览器数据后可能丢失。没有后端收集它们，未来如增加 AI 功能必须另外征得明确同意，并解释费用和隐私边界。

本作品涉及失去、焦虑与生命意义。它不是临床诊断或紧急危机干预。如面临迫切的自我伤害风险，请联系可信赖的人和所在地急救服务。中国大陆可拨打心理援助热线 **12356**，美国可拨打或短信 **988**。
