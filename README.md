# ARE YOU LOST? / 你也迷路了吗？

> **你是这一场戏的主角，但世界并不是为你搭建的舞台。**
>
> 竖屏黑白交互电影：从微小事件追溯因果，让真实的玩家通过镜头、文字、声音和选择参与一个不因自己而停下的世界。

## 体验 v0.3 · MONOCHROME CINEMA

**GitHub Pages（如已完成发布）**：[在浏览器中打开游戏](https://tera-dark.github.io/are-you-lost/)

手机浏览器可直接使用；电脑浏览器会显示居中的窄幅放映画面。

离线体验：点击本仓库 **Code → Download ZIP**，解压整个项目，再打开根目录的 index.html。**不要只下载一个 HTML 文件**：现在页面同时依赖同目录的 cinema.css 和 cinema.js，但不需要安装依赖或连接后端。

### 怎么玩

- **轻触银幕**：进入下一条对白，像逐镜观看互动电影；
- **跳过对白**：立即显示当前场景的可用选择；
- **右上角菜单**：切换自动放映、关闭动态排版、写私人笔记、查看记录、重新开始；
- **排版试镜**：在菜单中分别预览“杂念 / 放射”“压力 / 挤压”“虚无 / 消隐”“记忆 / 显影”，试镜不修改游戏进度，轻触银幕返回剧情；
- **SOUND OFF**：主动点击后才会开启低频环境音和合成胶片噪声，默认静音；
- **现实求助**：底部常驻入口，游戏不是临床诊断或危机干预工具。

## 设计宣言

见微知著：从一件小事开始，让玩家先观察、再行动、最后自发思考。

世界不因玩家而璀璨，社会不因玩家而运作；选择会产生后果，但不会保证如愿。玩家可以成为一场戏的主角，下一场戏的主角却可能是清洁工、街边陌生人或者某个从未看见玩家的人。

借鉴《史丹利的寓言》对选择权与旁白的反思、以及《心跳文学部》凝视屏幕外玩家的叙事方式，但不照搬其角色、台词、情节或关系。

## 目前的剧情与功能

- **34 个剧情节点、62 条预编写选项连接**，围绕前途、贫穷、工作、失去、意义与活着六个主题展开。
- **硬币的三种选择**：归还、放在台面、不去碰；另一人的镜头会揭示不同但不确定的后续。
- **画外世界**：独立事件以预编写叙事序列呈现。它不是一个在后台自主运行的现实城市模拟。
- **第四面墙**：经历两个主题后可以进入放映机背面，看到虚构角色如何理解屏幕外的真实玩家；不会装作知道玩家的真实姓名或私人生活。
- **跨主题回声**：之前触碰过的现实议题会在后续少量对白中出现。
- **本机笔记**：最多 600 字，手动保存、可导出 TXT 车票；旧版本游戏存档会在新放映界面中继续读取。
- **黑白竖屏放映系统**：逐条文字入场、四种情绪排版、可选自动放映、可关闭的本地合成环境声、减少动态效果模式。
- **零账号、零 API、零服务端存储**。本机笔记不会上传；清空浏览器数据会使存档丢失。

## 版本现状与边界

这是 **v0.3 叙事与视觉的可玩原型**，还不是完整的 60–90 分钟互动电影。音画联动目前以 CSS 动画和简单合成环境声为主，没有精确的 PV 节拍时间轴、复杂摄影机分镜或真实角色自主生活系统。

下一步优先做**镜头时间轴**、具体的日常行为与因果编辑器、手机真机视觉测试，再去扩展六大主题的叙事深度。我们的目标不是把哲学台词全部变成特效，而是让文字的运动与静止都来自具体剧情。

## 内容与安全

作品涉及现实困境、失去、迷茫和生命意义；不做所谓“治愈分”“积极分”，不会通过危险行为奖励特殊结局。现实困境不能简单归咎于个人心态。

如果有迫切的自我伤害风险，请联系信任的人和所在地急救服务。中国大陆可拨打 **12356** 心理援助热线，美国可拨打或短信 **988**。
