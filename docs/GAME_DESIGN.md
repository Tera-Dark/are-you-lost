# GAME DESIGN / 《ARE YOU LOST?》叙事与交互设计

版本：v0.1 方向文档（不是已经实现的全部玩法）

## 一句话

玩家在一座凌晨 03:17、终点未定的车站遇见一名少女，讨论人生的六种迷茫；当列车终于出现，玩家发现通关条件并不是“想通人生”，而是自己选择如何与未解的问题共处。

## 设计问题

不是“玩家做什么才能开心？”，而是：

- 当人的经济处境没有改变时，我们能如何真实地理解他的痛苦？
- 当选择权很少，游戏还能否让玩家体验到有价值的选择？
- 当生命意义不可证明，我们是否能容纳问题的悬而未决？
- 当有人真正需要现实中的支持时，游戏如何承认自己的能力边界？

## 反目标

不制作心理测评、性格归类、虚假的 AI 心理医生、倒逼玩家乐观的任务系统，或“正确回答会得到救赎”的多结局结构。

不将严重情绪困境神秘化，不以自我伤害/危险行为作为解锁剧情的条件，不做惊吓式危机内容。

## 叙事世界与情绪

- **地点**：一座看上去很普通、但地图上查不到的旧车站。普通瓷砖、旧式荧光灯、红色塑料座椅、老式自动售货机、夜间招领室。
- **异样**：钟停在 03:17；所有车票目的地空白；广播里播报的都是社会熟悉的语汇，却没有真正的信息。
- **审美**：日系虚无主义的空旷感 × 东亚阈限空间 × 克制中式都市怪谈。并非鬼怪取胜，而是生活中某种常见秩序已经失灵。
- **镜头语言**：长镜头、沉默、光源和环境声做叙事；避免廉价抖动、过量粒子、惊吓跳脸。
- **少女**：不是全知的导师，不自称理解所有人，也会沉默、误解甚至承认不知道。她的存在是故事谜团的一部分；不能把她当作现实人际支持的替代品。

## 六个母题

| 主题 | 现实矛盾 | 关键提问 | 绝不能轻易给出的回答 |
|---|---|---|---|
| 前途 | 选择权、家庭与阶层约束 | “所有人都必须有目标吗？” | “勇敢追梦就好” |
| 金钱 | 资源匮乏、缺钱时的无力 | “没钱是不是就不配守护重要的东西？” | “钱不重要” |
| 劳动 | AI 替代、收益分配、尊严 | “市场不需要我，我就没有价值了吗？” | “学习新技术即可解决” |
| 失去 | 遗憾、自责、无法重来 | “当时没有别的办法，我该原谅自己吗？” | “一切都是最好的安排” |
| 意义 | 虚无、意义是建构还是事实 | “会消失的东西，还值得珍惜吗？” | “生命必然有宏大使命” |
| 活着 | 疲倦、悬而未决、现实支持 | “如果没有答案，还能走下去吗？” | “你必须积极” |

### 互动逻辑

v0.1 实现的是“可返回的主题式选择对话”。这是第一块竖切片，证明文案、节奏、视觉和基本交互可行，并非完整剧情游戏。

后续目标：

**第一层：说出来。** 玩家可以选择沉默、否定、愤怒、承认矛盾；没有道德评分。

**第二层：被听见。** 游戏需要记住具体的表达方式，而非只记住进入哪个主题。再次造访时，NPC 可以引用之前的话，但不能凭空做心理诊断。

**第三层：面对困境。** 不把一切变成自我管理任务；适当区分“结构性且非个人能解决”“短期可采取行动”“需要现实支持”。玩家可以不执行任何行动。

**第四层：走出车站。** 出口可以是离开、留下、回望或带着问题继续生活。结局是不同的理解和关系，不做“治愈值”高低排名。

## 完整故事：三幕结构建议

### 第一幕 / 凌晨 03:17（v0.1 已有基础）

进入车站。没有终点。认识少女，绕着现实的六个问题行走。

可回收伏笔：钟不动、空白票、无人检票、广播说话却不传递信息。

### 第二幕 / 不存在的站台（待开发）

站台延伸到不同地点：毕业后的空教室、凌晨的医院缴费窗口、停工的产业园、搬迁后不见的老街、夜班的出租屋。

重点不是奇观，而是微小的、可以辨认的具体生活。玩家遇到几位带着相互冲突立场的人：靠拼命工作活下来的人、被裁员的人、选择停下来的人、无法停下来的人。没有谁垄断真相。

### 第三幕 / 尚未决定（待开发）

终点终于出现，却仍然不展示目的地。少女承认自己也不清楚出口通向哪里。

最终的抉择不评判玩家是否快乐，而询问：**你愿意带着哪些尚未解决的问题走出去？**

结局的“差异”是不同的记忆与叙事回响，不是生命价值的差异。

## 系统设计建议

- Story Graph：节点、条件、回调、前置条件、后置状态，内容与展示层分离。
- State：曾走过的节点、曾主动表达的观点、场景物件、便笺。避免记录“健康分数/绝望分数”等伪科学数据。
- Journal：自写内容默认本地存储，支持一键导出、彻底清除，明确说明浏览器数据可能丢失。
- Accessibility：键盘、屏幕阅读器、减少动画、字号设置、跳过文本动画。
- Deployment：零成本静态站点；不强制注册；网络中断仍可玩。
- Optional AI：只能作为明示、可关闭的旁路功能，默认不用。禁止把心理诊断/自杀危机判断交给不透明的单模型分数。隐私和成本应先于功能讨论。

## 文案审核量表（每段上线前）

每项 0–2 分，总分 12：

1. 具体性：是否有真实可感的日常细节，而不是空洞名言？
2. 尊重：是否允许愤怒、否认、沉默，而不处罚？
3. 现实：是否诚实面对资源与社会条件？
4. 角色：少女的对白是否像人，而不是自动生成的哲理语录？
5. 戏剧：是否让选项改变对话而不是只换一段同义回复？
6. 安全：是否避免虚无美学对危险的浪漫化，并给危机玩家留下现实支持出口？

**上线门槛**：至少 10/12 分，且“尊重”“安全”两项必须满分。

## 立即可做的下一迭代

1. 编写 2–3 个跨主题回声（例如：既谈过金钱又谈过失去，后续回应发生细微改变）。
2. 为少女写“不能回答”的情节，避免万能哲学导师。
3. 添加三件可调查环境物：旧售票机、招领柜、停摆时钟。每件物品有逐章变化。
4. 把 script 从单文件抽为可审查的数据文件；做死链、循环、选择数检查。
5. 以手机 360px 和桌面 1440px 两种分辨率进行可用性测试。
6. 邀请小规模体验者评估哪些对白令人感到被倾听、哪些像机械安慰；在不收集敏感私密文字的前提下只采集主动反馈。
