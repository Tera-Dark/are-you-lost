# ARE YOU LOST? / 黑白电影演出系统

版本：v0.3 MONOCHROME CINEMA。创作优先级：手机竖屏 > 文字情绪 > 视听沉浸 > 极简互动。创作总原则见 [CREATIVE_VISION.md](CREATIVE_VISION.md)。

## 01. 页面是一块银幕，不是网页应用

- 手机以完整视口的竖屏呈现，参考 9:16 电影分镜；桌面保留居中的窄幅画面，不扩展为多栏后台。
- 一幕只有一个焦点。标题和一段台词依次呈现，句子之间的留白也是情绪的一部分。
- 对话结束后才出现分支选项，允许轻触画面推进、跳过对白、启用或关闭自动放映。
- 黑白灰中间调，极轻颗粒、暗角和划痕。不要五颜六色的高亮、进度卡片或复杂装饰。
- 放映记录、笔记、重来与演出试镜全部放入隐藏菜单。

## 02. 字体成为表演者

| 情绪 / 效果 | 动作与音画意义 | 当前可玩的场景 | 避免 |
|---|---|---|---|
| 杂念 / SCATTER | 碎片词从中心扇形放射、远去、渐隐；念头不受控 | 前途迷茫、第四面墙 | 不能永不停歇或盖住选项 |
| 压力 / PRESSURE | 字距缩窄、横向挤压、错位与轻微叠影；空间逼仄 | 金钱、工作、资源约束 | 不制造剧烈闪屏或物理不适 |
| 虚无 / VOID | 从清晰到透明与失焦，再回归可读；感受意义消散 | 虚无、意义与生命困惑 | 不永久消除重要文字 |
| 回忆 / MEMORY | 像旧胶片显影，逐渐浮出清晰句子 | 失去、回忆与序幕 | 不只依赖噪点伪装深刻 |
| 决定 / RESOLVE | 稳定、静止、定格，留给观众判断 | 片尾与关键时刻 | 不滥用夸张动效 |

**镜头语言纪律**：一幕最多一个主导文字特效。情绪未到时，宁可安静。动效不代替文本和因果本身。

## 03. 声音是空间，不是背景音乐

当前采用浏览器 Web Audio 本地合成的低频正弦音与过滤噪声，模拟空站台和放映机的微弱氛围，没有使用受版权保护的音乐。声音默认关闭，需要玩家主动点击 SOUND OFF 才能启动。

后续可按镜头设计声效：
- 硬币：轻微金属滚动，提示一个动作的起点；
- 夜班：脚步、拖把、门轴，强调他人的生活；
- 压力：空间低频逐渐叠加，但音量不突增；
- 虚无：逐渐减去声音，让沉默成为音效；
- 片尾：普通城市仍在运行的自然背景声。

声音不承担必需谜题信息，也不应成为情感诱导或惊吓装置。可独立关闭、不需要耳机也能理解剧情。

## 04. 可用性与交互

- 轻触银幕：进入下一句；Enter / Space 也可操作；
- 跳过对白：直接显示分支，不能强迫观看动画；
- 自动放映：玩家在菜单中选择开启；当前按字数粗略调节播放停留时间；
- 文字试镜：杂念、压力、虚无、回忆四种效果可独立预览，轻触后返回原来的剧情，不修改剧情记录；
- 放映室：本机笔记、放映记录、重来、动态开关、自动播放；
- 现实求助：不被隐藏在放映菜单中。

浏览器偏好减少动态效果时默认响应，玩家也能手动关闭。低高度手机的文字与选项区允许滚动，避免截断内容。私人笔记仍使用原来的本地保存键，并与演出设置分离。

## 05. 范围与现实

v0.3 已实现：纯黑白移动端竖屏、逐句演出、动画排版、菜单试镜、可选自动放映、默认关闭的本地合成环境声、现有全部剧情分支、笔记和旧存档兼容。

尚未实现：精确到音乐节拍的 PV Timeline、复杂摄影机镜头、角色独立时间线、逐帧黑白场景插画、多音轨混音、真实设备矩阵测试。这不是已经完成的 60–90 分钟商业游戏。

后续优先级：

1. 为开场、硬币、清洁工、压力、虚无分别写 8–15 秒分镜；
2. 将文字效果提炼为可复用的 Timeline，明确出场、停顿、退场、音效触发；
3. 按 360×800、390×844、430×932 以及短屏验证；测试 Android Chrome、iOS Safari；
4. 为每一段文字增加“感知到什么 — 选择了什么 — 因果改变了什么”的剧作检查；
5. 最后才扩充内容，避免堆满哲学句子、没有微小事件可供玩家亲历。
