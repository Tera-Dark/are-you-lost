# ARE YOU LOST? — 创作宣言 / DIRECTOR'S NOTE

> 见微知著，从渺小的事件，引起自发的思考。从每一个行为，追溯本源的因果。
>
> 这个世界不因你而璀璨，这个社会不因你而运作。
>
> 每一个选择都可以影响轨迹，但最终是否如愿？这一点不得而知。
>
> 宛如 Meta 游戏中《史丹利的寓言》对于玩家行为的影响，《心跳文学部》里莫妮卡对屏幕外玩家的直接凝视。
>
> 这是一场电影，每一场戏都有一个主角。这也是一个真实的平行世界，一个真实的你曾经来这里亲身体会。
>
> 极简，放映，互动，分支。

以上来自创作者的核心理解，是整个作品的优先设计依据，而非可有可无的世界观点缀。

## 一句话定调

**你是这一场戏的主角，但世界并不是为你搭建的舞台。**

《ARE YOU LOST?》不是问答式人生指南，而是一部允许玩家留下痕迹、容纳未知结果、并时而凝视银幕之外的**交互电影**。世界本身以“真实的平行世界”作为叙事约定：它对剧中人真实，对屏幕外玩家也产生真实的思考与感受；但我们不会以此宣称电脑里真的存在有意识的生命，更不会假装知道玩家的真实身份、浏览历史或隐私。

## 五条必须写进玩法的法则

### 1. 一件小事，而非一篇大道理

每幕用一个微不足道的可见事件开场：找零掉下的一枚硬币、被雨打湿的收据、保洁员推过空站台、一盏忘记关的灯。

玩家先**看见**，再**选择**，最后才被允许推测意义。不要让角色抢先总结道理。小事没有标准诠释，不强行隐喻，不预告玩家“这一选择将改变一生”。

**反例**：NPC：“金钱能否决定人生意义？”

**正例**：机器下滚出一枚硬币，你蹲下来，发现已经有个人弯腰够了三次。

### 2. 因果不等于奖惩

选择影响世界状态、他人获得的信息与下一幕呈现的角度；**不保证结果如愿**。做到好事不必得奖，沉默不是坏结局。

一个动作至少带来三个层面：

- **直接影响**：你捡没捡起硬币？
- **他人视角**：没有你在场时，另一个人如何理解这件事？
- **未定后果**：多年后它意味着什么？玩家可能永远不得而知。

禁止“善良值 / 意义值 / 好结局概率”这类伪道德算法。因果应是可追踪的，不必是可预知的。

### 3. 世界不等你，镜头可以等你

站台时钟可以停在 03:17，但世界有自己的日程：保洁员下班、送货车进站、雨停、有人丢了工作、有人决定走路回家。

当玩家未做某事时，不是世界冻住；当镜头切去另一位人物，**那一幕的主角是别人**。配角拥有与玩家无关的目标和代价。玩家不是造物主，也不是一切不幸的根源。

### 4. 打破第四面墙，是为了看见“你”

参考《史丹利的寓言》对“选择”与“叙述者”的拆解，以及《心跳文学部》让虚构角色面对屏幕外真实玩家的方式；**借鉴机制和体验，不复刻具体角色、台词、桥段、独占式情感关系或惊吓操纵。**

影片内的“你”是角色；影片外的“你”是实际做出点击选择的人。某些镜头会意识到存在一位**观众兼参与者**，并询问：“你点了这个选项，真的是你想说的吗？还是这里只有这个选项？”

任何对现实玩家的“记忆”都必须建立在本机明确存储过的故事选择与回访次数上，不假装能看到摄像头、知道真实姓名或读取设备隐私。

### 5. 极简，是放映的纪律

- 一个镜头只服务一个可感知的情绪与因果。
- 字比特效重要，留白比说明重要。
- 画面由“片号 / 地点 / 事件 / 可选择的行为 / 幕外回响”组成。
- 让停顿、景别、光源、环境声音影响叙事，而不是堆按钮与信息卡。
- 不使用“完成度”“治愈评分”或提醒打卡驱动玩家。

## 叙事结构：三重真实

| 层级 | 谁是主角 | 谁能左右它 |
|---|---|---|
| 镜头内 / 你 | 玩家在站台中的化身 | 可选择行动，但无法控制结果 |
| 镜头外 / 他人 | 保洁员、夜班乘客、失业者、失去重要事物的人 | 他人有自己的因果链，不为玩家的到来停止 |
| 银幕外 / 玩家 | 握着鼠标、触碰屏幕的真实的人 | 可以退出、重来、拒绝回答；其真实选择值得尊重 |

三层之间可以彼此映照，但**任何一层都不应代替另一层发言**。

## 以“硬币”作为第一个可玩的微观实验

在原本的车站相遇之后加入一幕：

> 售货机下躺着一枚硬币。你不知道它属于谁。
>
> 站台尽头，夜班清洁工推着车走过去，鞋底拖出很轻的摩擦声。
>
> 你可以追上他、把硬币放上台面，或不碰它。

选择会改变硬币的下落，而不决定一个人的道德价值。后来，镜头可以跟随清洁工离开玩家，让人感受**世界对别人而言同样真实**。

重复进入片头、沿着选项走出不同路线之后，放映机可以向屏幕外的人发出一句并不越界的问话：“上一回，你选的也是这个吗？”它知道的只有影片内的本地记录，不是用户真实生活。

## 结局

不提供一个确定的“我找到了人生意义”。让玩家清楚：选择留下的是轨迹，不是承诺；自己曾经在这场影片里做过决定，但这并不证明世界从此属于自己。

最后一镜：

> 出口的门合上了。
>
> 镜头没有跟着你。
>
> 清洁工把拖把放回储藏间，摸出手机，看了一眼房租缴费提醒。
>
> 字幕：**电影结束了。世界没有。**
